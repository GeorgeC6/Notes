# 生物力学基础

## 课程简介

- 3 学分，专业选修课
- 授课老师：修鹏（4周），季葆华（8周），李学进（4节）
- 授课内容：生物力学和生物物理，重点是亚细胞和分子尺度的力学和物理。
    - 亚细胞尺度：细胞膜、细胞骨架、分子马达等
    - 分子尺度：DNA、RNA、蛋白质等生物大分子
    - 细胞尺度：细胞的迁移、黏附、分裂、集体行为等
    - 组织尺度：骨、脑、肌肉组织等（研究生课）
- 涉及的力学和物理方法
    - 连续介质力学
    - **热力学与统计力学**（分子尺度，热涨落不可忽略）
    - 计算机模拟（分子动力学模拟、蒙特卡洛模拟等）

!!! abstract "Grading"
    - 平时 40%（作业、出勤、随堂考）
    - 期末 60%（计算题 + 概念题，闭卷）
