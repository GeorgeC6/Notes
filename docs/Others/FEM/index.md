# 有限元方法

## 课程简介

- 2.5 学分，专业必修课

!!! abstract "Course Objective"
    - Understand the fundamental ideas of the finite element method (FEM)
    - Know the behavior and usage of each type of elements
    - Know how to choose appropriate element types, mesh density, and other parameters to perform a good finite element analysis (FEA)
    - Be able to interpret and evaluate the quality of FEA results, and understand the physics of the problems
    - Be able to use commercial FEA software (ANSYS/Abaqus) to perform structural analysis
    - Be able to write reports that clearly present the FEA results and their physical implications

!!! info "Grading"
    - Usual performance 40%
        - Homework
        - Project
        - Attendance
    - Final exam 60%
