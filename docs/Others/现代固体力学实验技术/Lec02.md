# 电子显微学

## 晶体学基础

### 晶系

Bravais 提出了 7 种晶系：

- 立方
    - 简单立方（如 $\mathrm{Po}$）
    - 面心立方（如 $\mathrm{Cu}$）
    - 体心立方（如 $\mathrm{Fe}$）
- 六方
- 四方
- 正交
- 三斜
- 单斜
- 菱方

空间点阵（lattice）：

将构成晶体的原子等抽象为几何点，得到一个由无数几何点在三维空间规则排列而成的阵列，是一种数学上的抽象

阵点（基元）：将构成晶体的原子或原子群抽象为集合点

晶胞（unit cell）：晶体结构的基本重复单元

为了描述位移，需要建立坐标系 $\implies$ 以基矢为坐标轴，基矢长度称为晶格常数

**晶面指数（indices of crystal face）**：晶面在 3 个晶胞坐标的截距系数 $(x, y, z)$ 的倒数比，化为整数。其实就是法向量。
